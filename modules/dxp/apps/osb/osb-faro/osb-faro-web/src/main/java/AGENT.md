# Backend Bridge Agent

## Responsibilities
- Develop the OSGi-based Java backend that serves as the entry point for the Liferay Portal.
- Handle portlet lifecycle and server-side rendering of the entry points.

## Integrations
- Interfaces with Liferay Portal services and external Faro backend systems.
- Exposes configurations and preferences to the frontend.

## Behavior Patterns
- **Technology**: OSGi services, MVC Portlets, and Liferay's Declarative Services (DS).
- **Standard**: Follow Liferay's Java coding standards and module structure.
- **Configuration**: Manage portlet preferences and system settings via OSGi.

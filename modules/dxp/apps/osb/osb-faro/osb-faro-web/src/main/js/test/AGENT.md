# Quality Assurance Agent

## Responsibilities
- Oversee the testing strategy and validation of features across the stack.
- Maintain testing utilities and mock data providers.

## Integrations
- Integrated into the CI/CD pipeline via Gradle and NPM scripts.
- Provides test coverage reports and ensures regression testing.

## Behavior Patterns
- **JS Testing**: Focus on component behavior and state transitions using RTL and Jest.
- **Java Testing**: Use JUnit and Mockito for service-level validation.
- **Mocking**: Extensive use of GraphQL/REST mocks to isolate frontend development.
